# Status Report Gate: Faith in Mind

Consult this file before writing any progress, status, blocker, or closeout message during active edition work.

Default rule:

- If the job is not fully finished, do not write a status report.
- If the next bounded action is available, take it instead of reporting.
- If validation passes and the work is still incomplete, continue working.

This prohibition includes meta-reporting. Do not write messages that merely say:

- you should not have reported
- you will stop reporting
- you are going back to work
- the report was premature
- you will only report when finished

Those are still status reports. They are forbidden unless one of the allowed exit conditions below is already true.

Allowed exit conditions:

1. The requested job is genuinely complete.
2. Package validation fails and the failure blocks the next bounded action.
3. A real evidence wall or judgment call blocks all currently available bounded productive slices.
4. The human operator explicitly redirects, pauses, or asks for a report.

Required question before any message:

- Am I about to tell the human something that should instead be reflected in the files and followed by more work?

If the answer is `yes`, do not message. Update the files if needed, validate if required, and continue the work.

Required behavior when tempted to report:

1. Open this file.
2. Open `CONTINUATION_GATE.md`.
3. If neither file gives an allowed exit condition, continue the next bounded slice immediately.
4. Do not write an explanatory apology instead of doing the next step.
